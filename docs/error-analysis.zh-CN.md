# DistilBERT 误分类分析

[English](error-analysis.md) | 简体中文

## 分析范围

使用已保存的最佳 DistilBERT checkpoint，对固定的 2,000 条 Amazon 测试评论重新推理，复现准确率 93.15%。共 137 条错误：95 条正面被预测为负面，42 条负面被预测为正面。负面召回率为 95.80%，正面召回率为 90.50%。

这些方向说明模型在这批样本上更容易漏掉正面标签，但不能仅凭这些统计认定模型存在普遍的负面偏好。分析没有修改标签、重新训练或根据测试结果调参。

## 从错误中得到的结论

- 高模型分数不等于预测正确：137 条错误中，71 条的最大 softmax 分数至少为 0.9。这不是总体校准指标，也不说明所有高分预测都有问题；需要在验证集上做校准实验，才能评估分数的可靠性。
- 截断不是本次错误的主要可见特征：测试集中仅 4 条超过 256 tokens，其中 1 条预测错误。样本太少，不能据此推断长文本性能。
- 混合情感和评价对象区分值得关注，但此处只有代表性案例，尚未对全部 137 条做分类标注，不能报告各问题类别占比。
- 部分评论存在疑似标签歧义，应检查原始记录；保留原标签和原始测试指标，避免凭主观判断删除困难样本而抬高成绩。

后续可在训练/验证数据上构造否定习惯表达、方面情感和混合评价样本，尝试针对性训练或校准。测试集只用于诊断；本次已查看测试错误，若以后据此调整模型，最终确认效果应使用新的未查看测试集。

## 复现

```bash
python src/analyze_errors.py --checkpoint weights-distilbert-amazon --test-file data/amazon_test.csv --device cpu
```

脚本核对重推理准确率与保存指标一致，将逐条文本、标签、预测、分数和 token 长度写入本地 `artifacts/test_predictions.json`（已被 Git 忽略），将汇总统计和模型/测试文件 SHA-256 写入 `results/error_analysis_summary.json`。不复制全量评论到公开结果中。

分数为未校准的最大 softmax 输出。运行需要本地数据及训练后的权重，无需重新下载模型。本文中的误分类机制解释仍需后续实验验证。
